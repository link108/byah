# blog-sources

Raw material for blog posts in progress — ChatGPT chat exports, notes, outlines. One subfolder per post, named with the post's slug (matches the eventual `src/content/blog/<slug>.md`).

Not built or served by Astro; it's just versioned working material for the `blog-post` skill (`.claude/skills/blog-post/`). Keep source files verbatim — don't edit them in place as the post evolves.
